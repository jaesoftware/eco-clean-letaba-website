# Eco Clean Letaba — R-J43 Technologies Demo

## Files
- index.html — complete website structure/content
- style.css — responsive design
- script.js — mobile menu, gallery filters/modal, scroll reveal and WhatsApp quote form
- assets/eco-clean-logo.jpg — supplied Eco Clean Letaba logo

## How to run
1. Keep all files/folders in the same structure.
2. Open `index.html` in Chrome, Edge or another browser.
3. The demo is responsive and can be tested on desktop or mobile.
